# UI 设计系统约定（apps/web）

> 适用范围：`apps/web` 前端界面。后端 API、数据契约与 `packages/*` 不受本文档约束。
> 视觉目标：权威、克制、清新、雅致的中文文章审校工具；以正文阅读与编辑审校为中心。

## 色彩

| Token | 值 | 用途 |
| --- | --- | --- |
| `--paper` | `#f4f1e9` | 页面桌面（暖灰） |
| `--paper-card` | `#fdfcf8` | 纸面卡片（正文、表单、批注卡） |
| `--paper-inset` | `#f8f5ee` | 卡片内凹区域（替换对照、输入框） |
| `--ink` | `#1d1a15` | 主文字（墨黑） |
| `--ink-2` | `#4f4a40` | 次级文字 |
| `--ink-3` | `#6f695b` | 弱提示文字（对纸面对比度 ≥ 4.5:1） |
| `--line` / `--line-strong` | `#e4ded1` / `#cec6b4` | 细分隔线 |
| `--accent` | `#b02e24` | 光明红：严重级、主按钮、选中态、品牌印点（克制使用） |
| `--gold` | `#8a6d1f` | 暖金：中风险、待核实、降级提示 |
| `--critical/high/medium/low` | `#b02e24` / `#b54708` / `#8a6d1f` / `#605a51` | 风险分级 |
| `--ok` | `#027a48` | 已接受、完成态 |

约定：不使用玻璃拟态、霓虹色、大面积渐变；阴影仅用于纸面分层。

## 字体

- `--serif`（Songti SC / Noto Serif SC / SimSun 等）：文章标题、正文、原文引用、替换对照、品牌字。
- `--sans`（PingFang SC / Noto Sans SC 等）：UI 控件、筛选、按钮、元信息。
- 元信息数字使用 `font-variant-numeric: tabular-nums`。

## 组件约定

- **报头 Masthead**：红色印点 + 宋体「光明审校」+ 英文小字；页面顶部 3px 红色规则线。不复制任何真实报纸商标。
- **正文纸面**：白卡 + 细边 + 题名下报纸式粗细双线（`.article-rule`）；段落首行缩进 2 字符。
- **正文批注 `.source-mark`**：2px 分级色底划 + 同色系 10% 晕染；选中态加深 + 墨色描边；`role="button"`、可 Tab 聚焦、Enter/Space 触发。
- **批注卡片**：`<article>` 容器（不做整体按钮）；标题即「定位原文」按钮；原文红条引用块在前；建议/改为分行；证据按中文 kind 标签（规则/文内对照/检索来源/模型判断）分行展示；操作按钮：接受（实心红）、忽略（线框）、待核实（金线框）。
- **状态反馈**：操作成功 toast（`role="status"`，2.6s 自动消失）；失败红色横幅（`role="alert"`）；降级金色横幅；全部处理完显示完成横幅；空态使用印章图标。
- **平板与手机（≤1023px）**：正文优先；审校意见为底部 Sheet（把手、圆角、投影、摘要条、`aria-expanded`）。收起只保留把手、摘要和展开操作，隐藏内容使用 `hidden` + `inert`，不可点击或聚焦。展开约 72vh，可内部滚动。

## 可访问性

- 全局 `:focus-visible` 2px 光明红描边。
- 正文色对纸面对比度 ≥ 4.5:1。
- `prefers-reduced-motion: reduce` 下关闭动画与平滑滚动。
- 进度条使用 `role="progressbar"` + aria 值。

## 断点

- 桌面：≥1024px（1440×900 为设计基准，双栏：正文自适应 + 批注栏 360–400px）。
- 平板：≤1023px（768×1024 为设计基准），单栏正文 + Bottom Sheet。
- 手机：≤720px（390×844 为设计基准），同样使用 Bottom Sheet，报头更紧凑。
